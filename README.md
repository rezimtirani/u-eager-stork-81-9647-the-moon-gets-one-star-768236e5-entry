## The entry

> One star. The moon only works nights, steals the sun's light, and still gets poems — I do overtime and nobody writes me a sonnet.

129 characters — inside the 200-character gate, single line, no padding.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, the file the house gate and judge read.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
